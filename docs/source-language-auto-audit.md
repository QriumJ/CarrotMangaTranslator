# 원문 언어 자동 기본값과 언어 고정 조사

2026-10-13, v3.3.6 이후 작업.

## 적용 계약

- 처음 설치, 저장된 번역 설정 누락, 잘못된 원문 코드의 기본값은 `auto`다.
- 이미 저장한 `ja`, `en` 등과 명시한 환경변수는 보존한다. 환경변수 기본값이
  일본어여도 저장된 `auto`는 일본어로 되돌아가지 않는다.
- 자동은 원문 전용이다. 대상 언어 기본값 `ko`는 유지하고 대상의 `auto`는
  설정/선택 번역 IPC에서 거부한다. 원문 자동 상태에서는 언어 교환을 막는다.
- 설정, 렌더러 초기화, 실행 옵션, OCR 캐시와 번역 재개 조건은 같은 원문 기본값을
  사용한다. 이전 `ja` 체크포인트를 `auto` 실행에서 잘못 재개하지 않는다.

## 실제 처리 경로

- 일반/영역 번역 프롬프트는 원문의 실제 글자와 배치에서 언어와 읽기 순서를
  판단하도록 요청한다. 여러 언어가 섞인 글도 특정 언어로 한정하지 않는다.
- 고정 블록 번역도 각 블록의 원문에서 언어를 판단한다. 내부 `jp`/`ko` 필드명은
  기존 저장/응답 계약이므로 바꾸지 않는다.
- OCR 명령과 자식 프로세스에 `auto`를 전달한다. Paddle의 자동 경로는 영어
  fallback 대신 다국어 인식 모델을 선택하는 `ch` 프로필을 사용한다. 이는
  원문을 중국어로 확정하는 값이 아니다. 명시한 기존 OCR 엔진/모델 선택은 보존한다.
- Hayai v2는 언어별 모델을 선택하는 구조가 아닌 다국어 인식 모델이다.
  `--source-language`의 기본값도 `auto`로 맞췄으며 실제 인식 모델은 바꾸지 않았다.
- 자동에서는 일본어 전용 ASCII/가나 잡음 제거, 일본어 전용 읽기 순서 추정과
  OCR 빈 결과만으로 번역을 생략하는 최적화를 적용하지 않는다.
- 자동/다른 언어의 효과음 원문 검증과 OCR 힌트에서 일본어 문자가 있어야 한다는 제한을 제거했다.
  사용자가 원문을 일본어로 명시한 경우에는 기존 문자 검증을 유지한다.
  대상 언어가 일본어인 경우 일본어 번역을 잔여 원문으로 거부하지 않는다.

모델 지원 범위는 자동 선택 기능과 별개다. Hayai v2는 CJK 중심이며, 자동 설정이
지원하지 않는 모든 문자의 OCR까지 보장하지 않는다. 언어 인식은 OCR/번역 모델이
실제 입력을 읽는 과정에서 수행하며, 별도 유료 언어 판별 요청이나 추측한 언어의
영구 저장은 추가하지 않았다.

처음 조사에서 제품에 연결되지 않은 조판 코드를 현재 제품 제한으로 설명하고,
자동에서 화 단위 글꼴 분석이 빠지는 회귀를 모델 제한으로 설명한 것은 잘못이었다.
글꼴 분석의 게이트는 `fontChapterSourcePolicy`가 앱 파이프라인과 MCP에서 공유한다.
자동 입력은 기존 C23 `is_style_character`가 분석하는 가나/한자가 있는 블록을 전달한다.
한자만 있는 블록도 보존하며, 이 판단을 원문의 언어가 일본어라는 판정으로 저장하지 않는다.
영어/한글만 있는 블록을 일본어 글자 모델로 강제하지 않으며 기존 일반 글꼴 경로와
독립적인 크기 분석은 유지한다. 명시한 일본어 설정, 모델 자산과 픽셀 판정 알고리즘은 보존한다.

다른 일본어 조건은 원문 삭제 가능성이 있는 ASCII/가나 잡음 제거와 읽기 순서 추정,
OCR 빈 결과를 이용한 번역 생략, 일본어 프롬프트 예시 등에 사용된다. 자동 모드에서
이를 모든 언어에 일괄 적용하지 않는다. 일반 OCR/번역, 효과음, 고정 블록 번역,
페이지 작업의 글꼴/크기 분석과 MCP 분석이 사라지는 기능 게이트와 구분해 조사했다.

## 검증

새/누락 설정, 명시 언어 보존, 자동 저장 왕복, 대상 자동 거부, 교환 버튼,
다국어 프롬프트, OCR 모델 선택/필터, 효과음, 재개 언어 불일치에 행동 테스트를 둔다.
프로덕션 설정 화면을 1600×980 및 1240×760으로 캡처하고 드롭다운 선택 강조,
잘림·겹침·외부 가로 스크롤을 확인했다.

`.tmp/production-cleanup-coverage-baseline-node22.json`의 원래 수치를 그대로 추가했다.
기존 기준 수치와 artifact SHA-256은 낮추거나 변경하지 않았다.
