# FLUX 말풍선 바탕 보존 — 2026-10-16

## 재현과 원인

사용자가 보고한 「최강의 검성, 미소녀 메이드로 전생해 빗자루로 무쌍하다」
11.1화 14페이지를 원본부터 재처리했다. 흰 사각 내레이션 안에 그림이 생성되거나
사각 테두리 안쪽에 둥근 풍선·곡선이 생기는 현상을 재현했다. PNG 알파가 투명해지는
문제가 아니라, 생성 모델이 흰 바탕을 다른 그림으로 대체해 투명해 보이는 사례다.

기존 `restoreFluxFlatBackground`는 최종 제약의 **바깥** 3px만 확인했다. 원문 제거
경계가 검은 프레임에 붙어 있으면 바깥 표본에 테두리/원화가 포함되어 단색 보정이
거부된다. 전역 Flux 프롬프트 변경으로 해결하려 하면 효과음·원화 복원과 충돌한다.
이전 실패 실험은 `flux-quality-20261004.md`, `flux-erasure-mcp-quality-20261009.md` 참조.

## 적용한 변경과 보호 조건

기존 바깥 표본 검사를 유지하고, 실패할 때만 다음 조건으로 내부 표본을 확인한다.

- 기존 사전 분석이 말풍선으로 판정한 창이며, 명시적 최종 제약과 독립적인 원문 core가 있어야 한다.
- 실행 시작 시점의 원본을 읽는다. 앞선 창의 생성 결과를 단색 근거로 사용하지 않는다.
- 제약의 각 연결 성분에서 경계 2px와 소유 core를 제외한다.
- 안쪽 3–5px 띠에 최소 64개, 전체 띠의 25% 이상 표본이 있어야 한다.
  4개 사분면 중 3개 이상에 각각 16개 이상의 표본을 요구한다.
- 띠뿐 아니라 나머지 **모든 비-core 내부 픽셀**도 검사한다. 흰 테두리 안의 그림,
  톤, 그라데이션을 흰색으로 채우지 않기 위한 조건이다.
- 채널별 중앙값 대비 최대 편차 24, RMS 5 이하라는 기존 기준을 유지한다.
- 작은 말풍선은 core가 종이까지 덮을 수 있다. 앞의 검사로 근거를 얻지 못하고
  core가 성분의 90% 이상을 소유할 때는 안쪽 2–3px 띠 전체를 별도로 검사한다.
  최소 64개/3개 사분면의 균일한 표본, 비-core 내부의 색 일치, 성분 전체의
  80% 이상이 같은 종이색이라는 조건을 모두 요구한다. 검은 옷 위의 작은 흰
  말풍선이 검게 지워지는 `diverse-9`의 추가 반례를 위한 보수적인 경로다.
- 후보 이미지만 보정한다. 실제 쓰기 범위, core 소유권, feather, 알파와 미선택 원문
  보호는 기존 합성기를 그대로 따른다. 조건을 충족하지 못하면 Flux 결과를 유지한다.

Gemma 번역 프롬프트, 출력 스키마, 샘플링, 모델 자산을 변경하지 않았다. 새 분류나
재질 판정을 Gemma에 요청하지 않으며, 보정으로 추가되는 Gemma 호출/토큰은 0이다.
Flux의 기존 bubble hint·native prompt·seed·4 steps도 유지한다.

추가 회귀 비교에서, 앞 말풍선의 보정 픽셀이 다음 Flux crop의 입력에 들어가 뒤쪽
무늬/효과음까지 달라지는 간접 영향도 확인했다. 최종 출력과 후속 추론용 bitmap을
분리했다. 후속 입력에는 기존 native 결과와 기존 바깥 띠 보정만 합성하고, 새 내부
종이색 보정은 최종 출력에만 적용한다. 두 합성 모두 기존 소유권/제약 합성기를
사용한다. 페이지 bitmap 하나의 메모리와 CPU 합성이 추가되며, 모델 호출은 늘지 않는다.
worker 입력 해시를 확인하는 characterization test로 이 경계를 고정했다.

## 판정의 한계

실제 효과음 전용 경로 60페이지의 원본/기준/후보 비교 시트 68장을 직접 확인했다.
59페이지는 기준과 픽셀까지 같고, `sfx-10`의 각진 말풍선에 남은 획만 추가로 제거됐다.
큰 흰 테두리 글자, 옷 위 글자, 분리된 획의 잔존과 망점 재생성 흔적은 기존 결과에도
남는다. `sfx-16`의 각진 효과음 풍선처럼 검출에서 말풍선 근거를 못 얻는 경우는
이 보정 대상이 아니다. 후보 2개에는 기존 완료 판정의 미완료 경고도 있었으며
`report.json`에 보존했다. 이 60페이지를 '효과음 제거 전부 성공'으로 세지 않는다.

미선택 일반 블록의 bbox도 별도로 감사했다. 기존에 붙여 넣은 render-only overlay
1개의 바탕 220픽셀이 변경됐고, 원문 보호 대상인 일반 대사 bbox의 변경은 0이었다.
이 overlay는 원래 `inpaintExcluded:true`이며 원문 권위가 없는 블록이다.

마스크 밖 변경 0, 원본 SHA 보존, 식자 객체 일치는 데이터·경계 보존 근거이지
마스크 안 원화 복원의 정답 점수가 아니다. 흰 원본 픽셀의 어두운 생성물 감소량도
보조 진단값이다. 실제 원본/수정 전/수정 후 crop을 별도로 시각 검수한다.

내부 표본이 부족하거나 검출이 잘못된 영역, 복잡한 원화 위 효과음, 무늬 재생성은
여전히 생성 모델과 마스크의 한계를 갖는다. 모든 만화에서 무조건 완벽하다는 보장은
하지 않는다. 이미 저장된 손상 출력을 이 수정이 소급 복구하지 않으며, 원본 기준으로
새로 처리한 결과에 적용된다.
