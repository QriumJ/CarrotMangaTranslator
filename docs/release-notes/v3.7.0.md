# v3.7.0

다국어용 HunyuanOCR을 추가하고 텍스트 편집과 서식을 하나의 패널로 합쳤습니다. 선택한 글자나 줄의 간격·그림자를 조절하고, 여러 블록의 말풍선 여백과 자동 지우기 제외를 함께 바꿀 수 있습니다.

## HunyuanOCR 1.5

- OCR 목록을 **HayaiOCR → HunyuanOCR 1.5 → PaddleOCR(레거시)** 순서로 정리했습니다. 기존 OCR 선택은 유지합니다.
- 일본어는 Hayai, 일본어 이외의 원문 언어는 Hunyuan을 추천합니다. 추천을 표시해도 사용자의 선택을 자동으로 바꾸지 않습니다.
- 기본 모델은 **F16**이며 메모리 절약용 **Q4**를 선택할 수 있습니다. 실행 장치는 자동·GPU·CPU를 제공합니다.
- 감지된 영역을 하나씩 인식하고 유휴 모델을 해제해 GPU 메모리 중첩을 줄였습니다. GPU 초기화·메모리 부족 시 같은 모델로 CPU 실행을 한 번 재시도하고 진행 상태에 표시합니다.
- Windows NVIDIA와 CPU에서 중국어·일본어·영어·스페인어 표본을 검증했습니다. AMD Vulkan과 Apple Silicon Metal은 실행 경로와 자동 테스트를 제공하며, 해당 장비에서의 Hunyuan 인식 실측은 완료하지 않았습니다.

## 통합 서식 패널과 부분 편집

- 기존 **텍스트**와 **서식** 탭을 **서식**으로 통합했습니다. 번역문과 원문 OCR을 위에 두고, 문자 서식·상세 문자 효과·블록 전체 설정을 나눴습니다.
- 블록 선택은 전체 문자, 번역문 선택은 선택한 문자, 입력 커서는 이후 입력할 문자에 적용합니다. 서로 다른 값은 혼합 상태로 표시하고, 글꼴·색상·숫자 입력을 조작해도 문자 선택을 유지합니다.
- 선택한 문자에 **행간·자간·장평·그림자**를 적용할 수 있습니다. 전체 글자 크기를 바꿔도 다른 부분 색상이나 강조는 유지합니다.
- 행간은 %로 표시합니다. 선택한 출력 줄과 앞줄 사이의 간격을 조절하며, 자동 줄바꿈과 세로쓰기에도 적용됩니다. **출력 줄 선택**으로 실제 말풍선의 줄을 선택할 수 있습니다.
- 시각·코드 편집, 저장·실행 취소, 고정·플로팅·별도 창에서 같은 서식 경로를 사용합니다. PSD에서 부분 서식을 편집 가능한 텍스트로 표현할 수 없는 경우 이미지 레이어로 보존합니다.

## 말풍선 여백과 작업 진행

- **말풍선 여백 0%**에서 글자 크기·외곽선에 따른 숨은 추가 축소를 제거했습니다. 기존 문서는 다시 말풍선 맞춤을 적용하면 새 기준을 사용합니다.
- **서식 → 블록 전체 설정**에서 선택한 블록들의 말풍선 여백을 입력하고 적용할 수 있습니다. 블록별 값을 저장하며 배치와 함께 실행 취소할 수 있습니다.
- 여러 블록의 **자동 지우기에서 제외**를 한 번에 설정하거나 해제할 수 있습니다.
- 페이지 작업의 페이지 수·단계 수·완료 작업 수를 구분했습니다. 예를 들어 80페이지 × 7단계는 총 560개의 단계 작업으로 표시하며, 작업 기록의 페이지 수는 80페이지로 유지합니다.
