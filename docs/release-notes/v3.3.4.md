# v3.3.4

Gemma 로컬 번역의 Temperature·Top P·Top K를 앱 설정에서 직접 조절할 수 있습니다.

## Gemma 번역 생성 설정

- **설정 → AI 모델 → 번역 → Gemma → 번역 생성 설정**을 펼쳐 세 값을 조절할 수 있습니다. 각 항목에 설명을 제공하며, API 설정과 별도로 저장합니다.
- 기본값은 **Temperature 0.1 / Top P 0.95 / Top K 64**입니다. **기본값 복원** 버튼은 이 세 값만 초기화합니다.
- 기존 설정 파일에 새 항목이 없으면 현재 앱 기본값을 적용합니다. 기존 환경변수가 지정된 경우에는 환경변수가 우선합니다.
- 추론 강도 설정은 추가하지 않았습니다. 말풍선 묶음 판정의 Temperature 0과 구조화된 번역의 추론 비활성화 정책을 유지합니다.
- 한국어·영어·일본어·중국어 간체·번체 설명을 제공합니다.

## 검증

- 저장 후 복원, 입력 범위, 기본값 복원, API 설정과의 분리, 환경변수 우선순위 및 실제 요청으로의 값 전달을 테스트했습니다.
- 실제 설정 화면을 1600×980과 1240×760에서 확인하고, 좁은 창에서는 최솟값·최댓값 입력도 검증했습니다.
- 전체 검사·커버리지 기준·빌드·Electron smoke가 통과했습니다. 플랫폼별 설치 파일은 릴리스 워크플로에서 추가로 빌드·검증합니다.
