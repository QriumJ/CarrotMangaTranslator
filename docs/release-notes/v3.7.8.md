# v3.7.8

작품·화 이름을 바꿀 때 결과 폴더도 함께 변경할 수 있고, 폴더 관련 작업을 해당 작품·화에서 바로 처리할 수 있습니다.

## 결과 폴더와 이름 변경

- 작품·화 이름 변경창에 **결과 폴더도 함께 변경** 선택을 추가했습니다. 기본으로 켜져 있으며, 체크를 끄면 제목만 바꾸고 폴더는 그대로 둡니다.
- 보관함의 작품·화 메뉴에서 **제목에 맞춰 폴더 이름 변경**을 실행할 수 있습니다. 선택한 작품 또는 화에만 적용되며, 사용자 지정 저장 위치는 변경하지 않습니다.
- 같은 이름의 폴더가 있으면 덮어쓰거나 합치지 않고 별도의 폴더를 만듭니다. 사용자가 수정·추가한 파일은 보존하며, 이동할 수 없는 경우 해당 화에서 확인하고 재시도할 수 있습니다.

## 작업 화면 개선

- 현재 화에서 결과물과 남겨 둔 이전 폴더를 열고, 폴더 이동 실패를 재시도할 수 있습니다. 설정으로 이동할 필요가 없습니다.
- 자동 저장을 꺼도 기존 결과물을 열 수 있습니다.
- 파일 보호 때문에 폴더 이동이 중단되면 자동 저장도 멈추고 해당 화에 표시합니다.
- 작품·화 메뉴의 불필요한 툴팁과 결과 폴더 구조 안내를 제거했습니다.

## 설치 파일과 서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.7.8.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.7.8-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 플랫폼별 SHA-256 checksum과 빌드 commit·workflow를 기록한 provenance를 함께 제공합니다.
