# v3.7.5

긴 출력 폴더명을 줄일 때 이름 끝에 공백이나 마침표가 남아 Windows에서 폴더를 다루기 어려워지는 문제를 수정했습니다.

## 결과물 출력

- 폴더명을 80자로 줄인 뒤 끝의 공백·마침표를 제거하도록 순서를 바로잡았습니다. 화별 출력과 원본 폴더 구조 유지 출력에 함께 적용됩니다. ([#163](https://github.com/ucx0204/CarrotMangaTranslator/issues/163))
- 이름 정리 후 사용할 문자가 남지 않는 경우의 기본 이름과 Windows 예약 이름 처리를 유지합니다.
- 절단 경계와 두 출력 방식의 실제 파일 저장을 확인하는 회귀 테스트를 추가했습니다.

이미 생성된 출력 폴더의 이름은 자동으로 변경하지 않습니다.

## 설치 파일과 서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.7.5.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.7.5-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 플랫폼별 SHA-256 checksum과 빌드 commit·workflow를 기록한 provenance를 함께 제공합니다.
