# v3.5.1

TXT·CSV·TSV로 번역문을 가져올 때 잘못된 페이지에 적용되거나 기존 편집이 사라질 수 있던 문제를 수정했습니다.

## TXT 가져오기와 저장

- **이슈 #155 수정:** 아직 번역문이 없는 OCR 블록에도 첫 번역을 가져올 수 있습니다.
- 새로 저장하는 TXT에 페이지·블록 식별 정보를 포함합니다. 페이지 이름이나 순서가 바뀌어도 같은 대상에 적용하고, 블록 내부의 빈 줄도 보존합니다. 식별 정보 줄은 유지하고 본문만 편집해 주세요.
- 기존 일반 TXT도 계속 불러올 수 있습니다. 파일 형식에 맞게 **번역문 TXT 불러오기** 또는 **원문+번역 TXT 불러오기**를 선택합니다. 화면 표시와 복사는 기존 일반 텍스트 형식을 유지합니다.
- 기존 TXT의 페이지 번호와 파일명이 충돌할 때 고유 파일명을 우선 확인합니다. 잘못된 원문+번역 파일을 번역문 전용 파일로 재해석하던 동작을 제거했습니다.
- 여러 페이지에 가져온 번역문을 한 번에 실행 취소·다시 실행할 수 있습니다. 연속으로 가져온 파일은 각각 별도의 편집 기록으로 남습니다.
- 중복된 페이지·블록, 불완전한 새 TXT, 내보낸 뒤 원문이 변경된 새 TXT는 적용 전에 거부합니다. 파일을 읽는 동안 편집 상태나 회차가 바뀐 경우에도 잘못 적용하지 않습니다.
- MCP의 TXT 내보내기에도 같은 형식을 적용했습니다. 기존 TXT 입력과 선택 범위·리비전·빈 문자열 변경 승인 정책은 유지합니다.

## CSV·TSV 검수표 가져오기

- 검수표를 현재 편집 상태에 적용하도록 수정했습니다. 파일을 읽는 동안의 편집이나 기존 실행 취소 기록을 저장된 회차로 덮어쓰지 않습니다.
- 필수 셀이 잘린 행과 중복 컬럼을 적용 전에 거부합니다. 구분자로 명시한 빈 셀을 통한 의도적인 내용 삭제는 계속 지원합니다.
