# v3.3.5

앱 안의 Codex·Claude 대화를 삭제할 수 있도록 하고, 채팅에 자동으로 표시되던 검수 요약 상자를 제거했습니다.

## 채팅 기록 관리

- 대화 선택칸 옆에 **대화 삭제** 휴지통 버튼을 추가했습니다. 선택한 대화를 삭제하면 남은 대화로 이동하며, 마지막 대화였다면 같은 AI의 새 대화를 엽니다.
- 작업 중인 대화는 먼저 중지한 뒤 삭제할 수 있습니다. 삭제가 실패하면 기존 대화를 유지하고 오류를 표시합니다.
- 삭제한 대화가 늦게 도착한 응답이나 앱 재시작으로 다시 나타나지 않도록 처리했습니다.
- 삭제 범위는 앱의 대화 기록입니다. 보관함, 원본, 출력물과 첨부 이미지는 보존합니다.

## 채팅 표시 정리

- 번역 가이드를 읽을 때 자동으로 표시되던 **미검수·해결할 항목 있음** 등의 검수 요약 상자를 제거했습니다.
- 기존 도구 실행 기록과 상세 응답은 계속 확인할 수 있습니다.

## 검증

- 세션 삭제, 마지막 대화 삭제 후 새 대화 생성, 실패 시 기록 유지, 늦은 이벤트와 재시작 후 복원 방지, IPC 호출 검증을 테스트했습니다.
- 실제 채팅 컴포넌트를 1600×980과 1240×760에서 확인했습니다.
- 전체 검사, 커버리지 기준, 빌드와 Electron smoke를 검증하며, Windows와 macOS 설치 파일은 각 릴리스 워크플로에서 추가로 빌드·검증합니다.

## 설치 파일과 서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.3.5.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.3.5-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 플랫폼별 SHA-256 checksum과 빌드 commit·workflow를 기록한 provenance를 함께 제공합니다.
