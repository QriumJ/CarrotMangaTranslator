# v2.8.5 — 페이지 처리 속도 개선과 폰트 오류 안내 보완

- 여러 페이지를 처리할 때 OCR 모델과 번역 세션을 같은 작업 단계 안에서 재사용해 페이지마다 반복하던 준비 비용을 줄였습니다. 각 페이지의 결과는 즉시 저장하며, 단계 종료·취소·실패 시 세션을 정리합니다.
- 원문 제거 전 말풍선 검출과 최종 배치가 같은 원본의 검출 결과를 공유하도록 개선했습니다. 캐시에는 용량과 항목 수 제한을 두고, 원본이 변경되면 다시 검출합니다.
- 이어서 실행할 때 선택한 페이지가 모두 완료한 단계는 준비 과정을 생략합니다. 일부 페이지만 완료된 폰트 단계의 기존 연속성 복원 동작은 유지합니다. ([#129](https://github.com/ucx0204/CarrotMangaTranslator/issues/129))
- 모델이 반환한 항목의 원문과 번역문 사이에 빈 줄이 있을 때 유효한 번역 응답을 해석하지 못하던 문제를 수정했습니다.
- 사용자 폰트를 등록하기 전에 실제 렌더링 엔진으로 로딩을 검사해 손상되었거나 지원되지 않는 파일을 미리 차단합니다. 검사한 데이터를 그대로 저장하고 동시 등록 시 목록을 보존합니다.
- 폰트 등록 실패를 화면에 알리고, 이미 등록된 폰트 때문에 출력이 실패하면 문제 폰트의 이름과 변경·재등록 방법을 오류 메시지에 표시합니다. 폰트 검사는 등록 시에만 실행하며, 출력 글꼴을 임의로 교체하지 않습니다. ([#130](https://github.com/ucx0204/CarrotMangaTranslator/issues/130))

## 배포 및 서명 안내

Windows x64 설치 파일과 Apple Silicon macOS 14 이상용 DMG·ZIP을 제공합니다.

Windows 설치 파일은 코드 서명되지 않았습니다. macOS 패키지는 임시 서명(ad-hoc)을 사용하며 Apple 공증을 받지 않았습니다.
