# v3.3.7

원문 언어의 기본값을 **자동**으로 바꾸고, 생성형 효과음 검수가 정상적인 과장 표현까지 오류로 판단하던 문제를 수정했습니다.

## 원문 언어 자동

- 처음 설치하거나 저장된 원문 언어 설정이 없으면 **자동 → 한국어**를 기본으로 사용합니다. 기존에 저장한 일본어·영어 등의 선택과 번역 대상 언어는 유지합니다.
- 일반 번역과 영역·블록·효과음 번역에서 실제 원문을 보고 언어를 판단하도록 했습니다. 여러 언어가 섞인 원문도 특정 언어로 고정하지 않습니다.
- 자동 모드에서 OCR은 기존 다국어 모델을 사용합니다. Hayai의 모델은 바꾸지 않았으며, 지원 범위는 각 OCR 모델에 따릅니다.
- 자동 모드에서 원문 글꼴 분석이 생략되던 조건을 수정했습니다. 기존 글꼴 모델이 지원하는 원문 글자를 분석하며, 설정을 일본어로 바꾸지 않습니다.
- 자동 모드에서도 번역 대상 언어에 맞지 않는 문자를 검사하고 해당 블록을 재시도합니다. 일본어 전용 잡음 제거 규칙이 다른 언어의 원문에 적용되지 않도록 했습니다.
- 원문 자동 선택을 저장·복원할 수 있고, 자동이 번역 대상 언어로 바뀌지 않도록 언어 교환을 제한합니다. 다른 원문 언어로 실행한 이전 작업을 잘못 재개하지 않도록 했습니다.

## 생성형 효과음 검수

- 긴 모음 줄기, 비대칭 자모 배치, 늘어난 획 등 효과음 특유의 과장 표현을 표준 글꼴 비율과 다르다는 이유만으로 거부하지 않도록 했습니다.
- 실제 글자가 달라지거나 획이 빠진 경우, 자모가 잘못 결합한 경우의 검수는 유지합니다.

## 검증

- 자동 설정 저장·복원, 기존 명시 언어 보존, OCR 실행 옵션, 번역문 검증, 글꼴 분석과 효과음 회귀 테스트를 포함합니다.
- 실제 원본 3페이지·15블록으로 명시한 일본어와 자동 모드의 글꼴 분석 결과가 같은지 확인했습니다.
- 보관된 효과음 이미지로 실제 모델 검수를 다시 실행해 정상적인 과장 표현은 통과하고 글자 결함은 계속 검출하는지 확인했습니다.
- 실제 설정 화면을 넓은 창과 최소 크기 창에서 확인했습니다. 전체 검사·빌드와 플랫폼별 패키징·실행 검증을 릴리스 절차에서 수행합니다.
