# v3.4.1

Flux 원문 제거에서 말풍선의 흰 바탕이 그림이나 검은색으로 바뀌는 사례를 개선했습니다. 말풍선 보정이 뒤쪽 효과음과 배경 처리에 영향을 주지 않도록 분리했습니다.

## Flux 말풍선 보존

- 사각 내레이션의 테두리 근처에서 바탕 보정이 빠져, 안쪽에 그림·곡선이 생성되던 사례를 개선했습니다. 검은 옷 위 작은 흰 말풍선이 검게 지워지는 사례도 보완했습니다.
- 기존 말풍선 판정과 원본의 충분한 단색 근거가 있을 때만 보정합니다. 그림·망점·그라데이션이 섞인 영역에는 이 보정을 적용하지 않습니다.
- 보정된 바탕이 다음 Flux 입력에 섞이지 않도록 분리해, 앞 말풍선을 고친 결과로 뒤쪽 효과음이나 배경이 달라지는 문제를 막았습니다.
- Gemma 번역 프롬프트와 Flux 생성 지시문은 유지했습니다. 보정에 추가 모델 호출이나 번역 토큰이 필요하지 않으며, 페이지 이미지 버퍼와 CPU 합성 비용은 추가됩니다.

## 검증과 적용 범위

- 서로 다른 원본 109페이지에서 129건 A/B 비교를 수행했습니다. 보고된 화 전체 14페이지, 다양한 작품, 효과음 전용 60페이지와 Gemma 4 12B로 새로 읽은 효과음 26개를 포함합니다.
- 허용 마스크 밖 변경·알파 변경은 0이었으며, 번역·식자 데이터와 후속 Flux 입력의 동등성을 확인했습니다. 이는 모든 효과음의 제거 성공을 뜻하지 않습니다. 복잡한 외곽선 효과음의 잔존과 배경 무늬 재생성 한계는 남아 있습니다.
- 테스트 10,937개와 커버리지 기준, 정적 검사, 빌드 및 Electron 스모크를 통과했습니다. 설치 파일은 플랫폼별 릴리스 workflow에서 패키징·실행 검증합니다.
- 기존 보관함과 저장된 출력은 변경하지 않습니다. 개선은 원본에서 새로 처리하는 결과에 적용됩니다.

## 설치 파일과 서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.4.1.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.4.1-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
