# v3.7.1

HayaiOCR·PaddleOCR·Flux의 Python 준비 중 체크섬 불일치로 설치가 실패하던 문제를 수정하고, 관련 런타임 다운로드와 캐시 검증을 보강했습니다.

## 설치 오류 수정

- 내용이 바뀌는 `get-pip.py` 주소 대신 기존 검증 해시와 일치하는 PyPA 커밋 주소를 사용합니다. HayaiOCR·PaddleOCR·Flux와 개발용 준비 스크립트에 함께 적용했으며, 체크섬 검증은 유지합니다. ([#157](https://github.com/ucx0204/CarrotMangaTranslator/issues/157))
- AMD ROCm SDK wheel 24개를 원래 파일명·내용·해시 그대로 고유 자산 릴리스에 고정했습니다. HayaiOCR와 네이티브 런타임이 같은 배포본을 사용합니다.
- VC++ 자동 설치 파일의 주소·버전·크기·SHA-256을 고정하고, 이미 받은 캐시도 실행 전에 다시 검증합니다. 손상된 캐시는 다시 받으며 해시가 맞지 않는 파일은 실행하지 않습니다.
- 진단용 Flux Diffusers 모델의 다운로드와 로딩을 같은 커밋에 고정했습니다. 커스텀 모델을 사용하는 경우 전체 40자리 revision을 지정해야 합니다.

## 검증

- 세 Python 런타임을 각각 빈 캐시에서 준비하고 pip 실행과 재사용을 확인했습니다.
- AMD wheel 24개 전체의 원본 해시와 크기, 게시 후 재다운로드 해시, 압축 해제를 검증했습니다. 빈 캐시 원격 설치와 Windows DLL 15개 로딩도 확인했습니다. AMD GPU 실물 장비에서의 추론은 이번 검증에 포함하지 않았습니다.
- 설치·캐시 손상·revision 변경 회귀 테스트와 원격 자산 검사를 추가했습니다. 자세한 범위는 [검증 기록](https://github.com/ucx0204/CarrotMangaTranslator/blob/v3.7.1/docs/issue-157-runtime-assets-audit.md)에 있습니다.

## 설치 파일과 서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.7.1.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.7.1-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 플랫폼별 SHA-256 checksum과 빌드 commit·workflow를 기록한 provenance를 함께 제공합니다.
