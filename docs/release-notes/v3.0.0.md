# v3.0.0

v2.8.6 대비 변경 사항입니다. 외부 AI 앱에서 당근을 조작하는 MCP 연결을 추가하고, 설정 UI·동시 작업·편집 및 저장 안정성을 개선했습니다.

## AI 앱 연결 · MCP

Codex·ChatGPT·Claude·Claude Code에서 실행 중인 당근의 보관함과 편집 도구를 사용할 수 있습니다. 연결한 AI가 번역문을 직접 작성해 저장하거나, 당근에 설정한 OCR·번역·이미지 모델의 실행을 요청합니다. 결과는 앱에 저장되어 직접 이어서 편집할 수 있습니다.

| 범위        | 지원 작업                                                                                                            |
| ----------- | -------------------------------------------------------------------------------------------------------------------- |
| 조회·검수   | 작품·화·페이지·블록 검색, 원본·부분 이미지 조회, 실제 앱 렌더링 미리보기, 검수 상태 확인                             |
| 번역·식자   | OCR·번역 실행, 번역문 교정, 블록 생성·영역·읽기 순서 편집, 폰트 견본·자동 크기·폰트 분석, 텍스트·서식·배치 일괄 수정 |
| 이미지      | 원문 제거, 마스크·이미지 수정, 효과음 처리, 외부 편집 이미지 반영                                                    |
| 문맥·보관함 | 용어집·인물·번역 규칙·장면 기억 편집, 인터넷 조사·제안 적용, 파일·웹 원고 가져오기, 작품·화·페이지 관리              |
| 출력·교환   | PNG·JPEG·WebP·PSD·ZIP 출력, `.mgtshare` 작업 교환, 텍스트·검수표·문맥 파일, 연결한 결과 폴더 동기화                  |

- **연결 설정:** 설정의 **AI 앱 연결 · MCP**에서 Tailscale 설치·로그인·HTTPS 연결을 준비하고 클라이언트별 안내를 확인합니다. 인증은 OAuth와 앱 내부 숫자 코드 승인으로 진행합니다.
- **권한 관리:** 이미지·출력 파일 전송, 텍스트·서식·문맥 편집, 블록·보관함 관리 및 모델 실행 권한을 구분합니다. 기본 조회 범위는 보관함 전체이며, 연결별 승인 철회와 앱 시작 시 자동 연결을 지원합니다.
- **작업 보호:** 편집 전 최신 상태·미리보기를 확인하고 저장 시 충돌을 검사합니다. 장시간 작업은 상태 조회·취소를 지원하며, 출력 완료 후 파일을 별도로 조회해 내려받습니다.
- **연결 안정성:** 인증 콜백 차단, 토큰 갱신 이력 누적, 발급 실패 후 재시도, 빠른 서버 재시작 문제를 수정했습니다.

연결 조건·클라이언트 등록·요청 예시·권한별 범위는 [MCP 사용 가이드](https://github.com/ucx0204/CarrotMangaTranslator/blob/v3.0.0/docs/mcp-user-guide.md)에 정리했습니다. MCP 사용 중에는 당근과 Tailscale이 실행 중이어야 하며, 앱 모델을 실행하는 작업은 해당 모델·계정 설정이 필요합니다.

## UI·사용 안내

- 설정의 상단 탭과 AI 하위 탭을 **왼쪽의 단일 목록**으로 통합했습니다. 일반·서식·단축키, 번역·OCR·이미지·조사·하드웨어, 결과물·MCP, 확인·업데이트에 바로 접근할 수 있습니다.
- 버튼·입력·선택 컨트롤과 팝업을 정리했습니다. 선택 상태는 강조색 테두리·배경으로 통일하고, 블러·그라데이션·과한 등장 효과를 줄였습니다. 좁은 창과 확대 화면에서 설정·가져오기·조건부 편집의 배치와 스크롤도 보완했습니다.
- README를 현재 화면과 기능별 사용 순서로 다시 작성했습니다. 편집·효과음·조건부 일괄 편집·출력·자동 저장·작업 공유·백업·MCP 안내와 실제 UI 캡처를 포함합니다.

## 동시 작업·성능

- 서로 다른 페이지를 대상으로 하는 **API·Codex 기반 작업**을 함께 실행할 수 있도록 작업 잠금을 분리했습니다. 짧은 로컬 검출·OCR·폰트·배치 단계는 순서대로 GPU를 사용하고, 외부 응답 대기는 겹쳐 처리합니다.
- 로컬 Gemma 번역·로컬 원문 제거처럼 모델을 독점하는 작업과 같은 페이지를 수정하는 작업은 계속 충돌을 검사합니다. 취소·모델 해제가 끝나기 전에 다음 작업이 자원을 사용하는 경로도 차단했습니다.
- 여러 페이지 처리 중 같은 모델을 재사용하고, 페이지 소유권 확인의 중복 읽기를 줄였습니다. PNG 검증·픽셀 합성을 워커로 옮겨 큰 이미지 처리 중 메인 프로세스가 멈추는 시간을 줄였습니다.

## 오류 수정

- **완료 알림음:** Hayai 페이지 작업, 다른 작업이 진행 중일 때 끝난 작업, 여러 작업이 연속 완료된 경우 알림음이 빠지는 문제를 수정했습니다. 중복 완료 이벤트는 한 번만 알리고, 음소거·작업별 설정을 유지합니다.
- **화 전환:** 전환 직전의 최신 편집 저장을 기다리며, 확인창을 연 뒤 추가한 마스크도 폐기 여부를 다시 확인합니다. 저장 실패 시 편집 내용을 유지합니다.
- **블록 편집:** 연속 입력을 묶은 뒤 Undo 상태가 갱신되지 않는 문제와 반복 복제 시 ID가 길어지는 문제를 수정했습니다. 생성·복제·보관함 삽입에 페이지당 500개 제한을 일관되게 적용합니다.
- **작업 공유:** 가져오기 준비 중 추가된 화와 최신 페이지 편집을 보존하고, 공유 효과음 기록의 블록 참조를 새 ID에 맞게 변환합니다. 다른 PC의 작업 이어하기 식별자가 섞여 잘못된 화를 재개하지 않도록 수정했습니다.
- **출력 갱신:** 번역문 대신 표시되는 원문을 수정했을 때도 출력 변경으로 인식합니다.
- **백업·압축 처리:** 대량 파일 목록에서 발생할 수 있는 배열 처리 오류를 수정하고, 파일 수 제한·취소 검사를 보강했습니다. ZIP의 정상 폴더 항목을 파일로 세는 문제도 수정했습니다.
- **의존성:** ZIP 처리 라이브러리와 취약점이 보고된 전이 의존성을 갱신했습니다.

## 설치 파일·서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.0.0.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.0.0-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 모델·런타임은 앱에서 별도로 내려받습니다. 플랫폼별 `SHA256SUMS`와 provenance 파일에서 설치 파일 해시와 빌드 커밋을 확인할 수 있습니다.
