# v3.4.2

설정 화면에서 앱의 모델 폴더를 바로 열 수 있도록 버튼을 추가했습니다.

## 모델 폴더 열기

- 설정 하단의 **로그 폴더 열기**와 **오류 보고** 사이에 **모델 폴더 열기** 버튼을 추가했습니다.
- 앱 데이터 경로의 `models` 폴더를 탐색기 또는 Finder로 엽니다. 폴더가 아직 없으면 생성하며, 기존 파일은 유지합니다.
- 폴더 열기에 실패하면 앱 상태 메시지로 안내합니다. 한국어·영어·일본어·중국어 간체·번체 문구를 지원합니다.
- 기존 공통 버튼 스타일과 사용 중 비활성화 동작을 적용했습니다. 실제 설정 화면의 넓은 창과 좁은 창에서 배치를 확인했습니다.

## 설치 파일과 서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.4.2.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.4.2-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 플랫폼별 SHA-256 checksum과 빌드 commit·workflow를 기록한 provenance를 함께 제공합니다.
