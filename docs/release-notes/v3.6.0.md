# v3.6.0

작품별 화 선택 삭제와 용어집 파일 교환을 추가하고, 보관함·설정·채팅·편집 도구의 작업 흐름을 정리했습니다.

## 보관함과 작품 용어집

- **이슈 #156:** 작품 메뉴에서 여러 화를 골라 삭제할 수 있습니다. 목록 안에서 선택하고, 선택한 화·페이지 수와 삭제 범위를 확인한 뒤 실행합니다. 실패한 화는 결과에 남겨 다시 처리할 수 있습니다.
- 작품·화의 이름 변경과 삭제를 각 항목의 작업 메뉴로 모았습니다. 이름 변경창은 이름 편집에만 사용합니다.
- 별도 출력 폴더의 파일 삭제는 기본으로 선택하지 않습니다. 삭제 확인창에서 직접 선택할 수 있습니다.
- 화를 열지 않아도 작품 메뉴에서 해당 작품의 용어·기억을 열 수 있습니다.
- 작품의 용어집과 캐릭터 정보를 JSON 파일로 내보내고 다른 작품에 가져올 수 있습니다. 중복·충돌·잘못된 항목을 검토한 뒤 편집 초안에 반영하고 저장합니다.
- 가져오기 검토와 인터넷 조사 화면이 기존 편집창 위에 겹치지 않도록 정리했습니다. 취소하면 편집 초안을 유지한 채 돌아옵니다.

## 설정과 채팅

- 저장이 필요한 설정과 즉시 적용되는 연결·파일 관리를 구분했습니다. 다른 탭에 저장하지 않은 설정이 있으면 저장·취소 버튼을 유지합니다.
- 폰트 파일 등록·삭제를 별도 관리 화면으로 나눴습니다. 돌아와도 폰트 설정 초안을 유지하며, 삭제 실패 안내는 직접 닫을 때까지 남습니다.
- 지원·진단 작업을 확인 탭으로 모으고, Grok 계정 관리는 Grok 채팅에서 열도록 옮겼습니다.
- 열린 화가 없는 화면에서는 편집 도구가 채팅 진입을 가리지 않도록 했습니다. 전체 작업 상태는 계속 확인할 수 있습니다.
- 조건부 일괄 작업의 고급 도구와 순서 편집은 필요할 때 펼칩니다. Flux 실행 백엔드는 Flux 모델을 선택했을 때 표시합니다.

## 조작과 안내

- 도구 모음을 키보드 방향키·Home·End로 탐색할 수 있습니다. 탐색만으로 도구가 실행되지는 않습니다.
- 작업 메뉴가 사이드바나 스크롤 영역에 잘리지 않도록 공통 팝업 위치 처리를 적용했습니다.
- 반복 설명을 줄이고 보충 정보는 툴팁과 접힌 도움말로 정리했습니다. 삭제 결과·권한 승인·오류에 필요한 정보는 화면에 유지합니다.
- MCP 주 화면과 조건부 작업 고급 도구의 다국어 문구를 정리하고, 출력 토큰 오류의 설정 경로를 실제 번역 탭에 맞췄습니다.
