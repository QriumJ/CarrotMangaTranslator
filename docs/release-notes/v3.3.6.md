# v3.3.6

새 버전 번역의 작업 시간 기록, 여러 폴더 가져오기, 설정 기억과 보관함 접기를 개선했습니다. 앱 전체의 색상과 선택 표시를 공통 팔레트로 맞추고 가져오기·작업 기록 화면을 간결하게 정리했습니다.

## 번역 기록과 완료음

- **일반 번역 → 새 버전**으로 실행한 작업도 단계별 소요 시간과 실행 이력을 기록합니다. 재개한 작업은 별도 실행으로 구분하고 기존 번역 기록도 계속 확인할 수 있습니다.
- 측정하지 않은 시간, 0초, 건너뛴 단계를 구분하고 실패·취소·중단 상태를 표시합니다. 기록 저장 실패가 실제 번역 결과를 바꾸지 않도록 했습니다.
- 완료음이 겹치거나 재개 작업에서 누락되는 문제를 수정했습니다. 작업 정리가 끝난 뒤 성공을 알리고, 음소거 중 쌓인 소리가 나중에 재생되지 않도록 했습니다.
- 완료음 앞에 짧은 무음 구간을 추가했습니다. HDMI/DP 장치의 절전 복귀에 따른 첫 소리 잘림은 기기별로 차이가 있어 실제 청취 확인이 필요합니다.

## 여러 폴더 가져오기와 보관함

- 여러 폴더를 한 번에 선택해 화를 가져올 수 있습니다. 원본의 상대 경로를 유지하고, 같은 이름의 폴더가 있어도 출력 경로가 충돌하지 않도록 구분합니다.
- 가져올 화를 전체 선택·해제하고, 기존 작품에서 제목이 같은 화를 선택적으로 건너뛸 수 있습니다. 모든 화가 중복이면 결과만 알리고 번역 설정을 열지 않습니다.
- 가져온 뒤 번역 설정을 열지 않고 가져오기만 마칠 수 있습니다.
- 작품별 접기·펼치기와 전체 접기·펼치기를 지원하고 접힌 상태를 기억합니다. 검색 중 임시로 펼친 상태는 저장된 접기 상태를 덮어쓰지 않습니다.

## 설정 기억과 출력

- 출력 형식, JPEG/WebP 품질, 원본 이름 유지, 저장 위치 방식을 기억합니다. 창을 빠르게 닫거나 다시 열어도 오래된 저장 응답이 최신 선택을 덮어쓰지 않도록 했습니다.
- 브러시 크기·색상, 웹 이미지 크기 필터, 도구 모음과 패널 상태, 목록 정렬, 가져오기 옵션 등 반복해서 쓰는 선택을 기억합니다.
- 번역 작업 아래에 이미지·PSD 출력 진입점을 고정했습니다. 버튼·명령 팔레트·단축키가 같은 출력 동작을 사용합니다.
- 덮어쓰기 등 실행마다 확인해야 하는 선택은 자동으로 복원하지 않습니다.

## 화면 정리

- 선택·활성·포커스에는 당근색 강조를 유지하고 진행·성공·경고·오류는 공통 상태색을 사용합니다.
- 가져오기 목록의 큰 선택 상자와 설명 배너를 없애고 행과 간격을 줄였습니다. 보조 설명은 툴팁으로 옮겼습니다.
- 작업 시간 화면의 반복 설명과 장식을 줄이고 기존 공통 컨트롤과 밀도를 맞췄습니다.
- 번역과 페이지 작업의 시간 기록을 하나의 실행 목록과 단계별 표로 통합했습니다. 기존 번역 기록도 같은 화면에서 확인할 수 있습니다.

- 전체 회귀 테스트, 커버리지 기준, 타입·스타일·의존성 검사와 프로덕션 빌드를 통과했습니다.
- 실제 가져오기·출력·설정·작업 기록·사이드바 컴포넌트를 넓은 창과 최소 크기 창에서 확인했습니다.
