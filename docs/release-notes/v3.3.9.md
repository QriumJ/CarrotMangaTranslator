# v3.3.9

색상 선택을 앱 안에서 바로 할 수 있도록 바꾸고, 글자와 브러시 등 여러 도구에서 함께 쓰는 팔레트를 추가했습니다.

## 앱 내부 색상 선택기

- 운영체제 색상 대화상자 대신 앱과 같은 스타일의 색상 선택기를 사용합니다.
- 채도·명도 영역과 색조 슬라이더, HEX·RGB 입력으로 색을 고를 수 있습니다. 키보드로도 값을 조절할 수 있습니다.
- 글자·외곽선·그림자, 보정 브러시, 텍스트 모으기, 기본 서식과 조건부 일괄 편집에 같은 색상 입력을 적용했습니다.
- 색을 드래그하는 동안 변경 전달 빈도를 조절하고, 선택 완료 시 마지막 값을 반영합니다.

## 공유 팔레트와 색 추출

- 자주 쓰는 색을 최대 24개까지 저장하고 여러 색상 입력에서 공유합니다. 앱을 다시 실행해도 팔레트를 유지합니다.
- 현재 색 추가, 저장된 색 선택, 우클릭 또는 Delete·Backspace로 색 삭제를 지원합니다.
- 기존 `P` 색 추출 단축키와 `Alt+클릭` 원고 색 추출을 유지합니다. 도구 모음에는 별도 색 추출 버튼을 추가하지 않습니다.

## 검증과 테스트 안정성

- 실제 색상 선택기와 브러시 컴포넌트를 넓은 창과 좁은 창에서 확인했습니다.
- Windows CI의 디스크 저장·정리가 늦을 때 MCP 통합 테스트의 내부 대기가 전체 테스트 제한 시간보다 먼저 끝나지 않도록 조정했습니다. 앱의 제한 시간과 테스트의 상태·정리·실행 취소 검증은 유지합니다.
- 로컬 테스트 10,878개와 커버리지 기준, 정적 검사·빌드·스모크 검사, 내장 원격 모델 자산 36개 검증을 통과했습니다. 플랫폼별 설치 파일은 릴리스 workflow에서 패키징·실행 검증합니다.

## 설치 파일과 서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.3.9.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.3.9-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
