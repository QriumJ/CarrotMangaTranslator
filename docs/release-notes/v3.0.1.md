# v3.0.1

v3.0.0 대비 페이지 선택 동작을 바로잡은 패치 릴리스입니다.

## 오류 수정

- 번역·결과물 출력·자동 인페인팅·페이지 작업에서 Shift 클릭으로 같은 화의 페이지 범위를 선택하거나 해제할 수 있습니다. Ctrl 클릭은 한 페이지만 전환합니다.
- 회차의 모든 페이지가 선택돼 있을 때 회차 체크박스를 한 번 클릭하면 바로 전체 해제됩니다. 전체 선택·해제와 회차 선택 뒤에는 이전 Shift 선택 기준이 남지 않습니다.
- 결과물 출력과 자동 인페인팅의 페이지 목록에 현재 페이지 표시와 자동 스크롤을 연결했습니다.
- 페이지 작업은 선택 표시를 선택·해제 두 상태로 통일했습니다. 번역 재개 가능 페이지에서도 추가 클릭 없이 대상을 선택할 수 있으며, 기존 페이지 작업 재개 요청 형식은 유지합니다.

## 설치 파일·서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.0.1.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.0.1-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 모델·런타임은 앱에서 별도로 내려받습니다. 플랫폼별 `SHA256SUMS`와 provenance 파일에서 설치 파일 해시와 빌드 커밋을 확인할 수 있습니다.
