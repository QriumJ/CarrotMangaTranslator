# v3.3.3

번역 설정이 실제 요청에 그대로 반영되도록 수정하고, FLUX 원문 제거와 폰트 자동 맞춤의 실행 안정성을 개선했습니다.

## 번역 설정

- Gemma의 기본 입력값을 temperature **0.1**, top-p **0.95**, top-k **64**로 맞췄습니다.
- 기존 블록 보정과 고정 블록 번역에서 사용자가 지정한 샘플링 값을 강제로 덮어쓰던 처리를 제거했습니다. temperature를 `0`으로 지정한 경우에도 그대로 전달합니다. 그룹 분류 단계의 temperature `0`은 유지합니다.
- 로그에 실제 HTTP 요청으로 전송한 생성 설정을 기록하며, 설정부터 최종 요청까지 값이 일치하는 회귀 테스트를 추가했습니다.

## 원문 제거와 GPU 메모리

- FLUX를 불러오기 전에 페이지의 말풍선·마스크 분석을 완료하고, 분석 모델의 GPU 메모리 해제가 끝난 뒤 원문 제거를 시작합니다. 일반 원문 제거, 페이지 작업, 영역 번역과 효과음 제거에 함께 적용됩니다.
- 많은 페이지나 큰 마스크 때문에 분석 결과 캐시가 밀려나 FLUX 실행 중 다시 GPU 분석을 시작하던 경로를 없앴습니다. 작업 중 분석 결과는 마스크 값을 보존하는 임시 파일로 보관합니다.
- 해상도를 낮추거나, 메모리 부족으로 실패한 뒤 재시도하는 처리는 추가하지 않았습니다.

## 폰트 자동 맞춤과 오류 표시

- 실제 OCR 실행 환경의 Python 버전을 확인해 호환되는 폰트 패키지를 선택합니다. 기존 Python 3.12 환경에서 Python 3.14 전용 NumPy를 읽어 실패하던 문제를 수정했습니다. 개발 실행과 설치본에 같은 선택 로직이 적용됩니다.
- 기존 Python·PyTorch·CUDA 환경은 유지합니다. 이번 버전은 Python 버전을 3.14.8로 일괄 변경하지 않습니다.
- 긴 Python 오류 메시지가 화면 전달 길이 제한을 초과해 실패 상태가 표시되지 않던 문제를 수정했습니다. 화면에 보낼 메시지는 길이를 제한하고 전체 진단 내용은 로그에 남깁니다.

## 검증 범위

- 전체 검사와 테스트 10,658개를 통과했습니다. 설정 전달, 대량 페이지·큰 마스크 보존, GPU 해제 순서와 긴 오류 전달을 검사했습니다.
- 기존 Python 3.12.7과 설치본의 3.14.8 실행 환경에서 실제 폰트 worker를 실행해, 실패 작업의 원본 2페이지에 대한 11개 선택 결과가 일치하고 원본 파일이 변하지 않았음을 확인했습니다. 26페이지 전체 작업 재실행 결과는 아닙니다.
- 두 폰트 패키지를 다시 내려받아 크기·SHA-256·내부 파일을 검사하고 네이티브 라이브러리 로딩과 모델 기준 출력 검증을 통과했습니다.
- GPU 메모리 개선은 실행 순서와 데이터 보존 테스트로 검증했습니다. 제보자의 8GB GPU에서 실제 작업을 재현한 결과는 아닙니다.
