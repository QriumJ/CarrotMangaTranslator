# v2.8.6 — MTP 메모리 자동 배분 보완과 보정값 재사용

- Windows CUDA 환경에서 Gemma MTP 보조 모델의 메모리가 자동 배분 계산에서 누락되어 번역 모델이 지나치게 느려지는 경우, 실제 VRAM 여유와 CUDA 메모리 예산 차이를 반영해 한 번 보정하고 다시 검사합니다. 기존 서버가 종료된 뒤 새 서버를 시작하며, 정상적으로 실행되는 경우에는 재시작하지 않습니다. ([#131](https://github.com/ucx0204/CarrotMangaTranslator/issues/131))
- 성공한 보정값을 저장해 다음 작업과 앱 재실행에서도 재사용합니다. 모델·런타임·GPU·실행 설정과 현재 메모리 상태를 비교해 적용하며, 조건이 크게 달라지거나 보정값으로 실행에 실패하면 다시 판단합니다. 재사용할 때도 짧은 성능 검사는 유지합니다.
- 보정 과정에서 사용자가 저장한 VRAM 여유 설정, 컨텍스트 길이, 최대 출력 토큰과 MTP 사용 여부를 변경하지 않습니다. 메모리 측정이 불가능한 경우를 여유 메모리 0으로 처리하지 않으며, VRAM 부족이 확인되지 않은 성능 검사 실패는 구분해 안내합니다.

이번 변경은 앱에서 메모리 배분을 보완하는 수정이며, 내장 llama.cpp 버전은 변경하지 않았습니다.

## 배포 및 서명 안내

Windows x64 설치 파일과 Apple Silicon macOS 14 이상용 DMG·ZIP을 제공합니다.

Windows 설치 파일은 코드 서명되지 않았습니다. macOS 패키지는 임시 서명(ad-hoc)을 사용하며 Apple 공증을 받지 않았습니다.
