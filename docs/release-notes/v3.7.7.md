# v3.7.7

Codex·Claude·Grok 실행기를 업데이트하고, 화면의 중복 안내 문구와 툴팁을 정리했습니다.

## AI 실행기 업데이트

- Codex를 **0.164.0**으로 업데이트했습니다.
- Claude Code를 **2.1.311**, Claude Agent SDK를 **0.3.311**로 업데이트했습니다.
- Grok Build를 **1.0.70**으로 업데이트했습니다.
- Windows x64와 Apple Silicon macOS의 자동 설치 파일과 무결성 검증 정보를 함께 갱신했습니다.

## 화면 정리

- 번역 원본 선택, 페이지 선택, 내보내기, 일괄 편집, 설정과 채팅 로그인 화면의 중복 안내 문구·툴팁을 줄였습니다. 오류와 진행 상태 안내는 유지합니다.
- 열린 화가 없을 때 오른쪽 상태 표시 버튼이 하단에 배치되도록 수정했습니다.

## 설치 파일과 서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.7.7.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.7.7-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 플랫폼별 SHA-256 checksum과 빌드 commit·workflow를 기록한 provenance를 함께 제공합니다.
