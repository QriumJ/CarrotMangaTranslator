# v3.5.0

앱 채팅에 **Grok Build**를 추가하고, Claude Code·Codex·Grok 실행 파일을 처음 사용할 때 내려받도록 바꿨습니다.

## Grok 앱 채팅

- 채팅의 도우미 선택에서 **Grok**을 선택할 수 있습니다. 설정의 **AI 앱 연결(MCP) → 앱 채팅 · Grok 계정** 또는 채팅 화면에서 공식 계정으로 로그인합니다.
- 공식 Grok Build CLI와 ACP 연결을 사용합니다. 모델·추론 수준 선택, 이미지 첨부, 대화 이어받기, 대화 압축, 중지와 질문 응답을 지원합니다.
- 당근 MCP 도구를 통해 보관함 조회와 번역·편집을 요청할 수 있습니다. Grok은 앱 채팅에서 사용하는 도우미이며, 자동 번역 엔진 목록은 기존 구성을 유지합니다.
- 실제 앱에서 테스트 이미지의 문자·도형 인식과 MCP 서버 정보 조회를 확인했습니다. 대화 재연결 후 이미지 내용 기억과 대화 압축도 검증했습니다.

## 더 가벼운 설치와 첫 연결 안내

- Windows와 macOS 설치 파일에서 Claude Code·Codex CLI 실행 파일을 분리했습니다. Grok도 처음 연결할 때 공식 배포본을 내려받습니다.
- 사용할 수 있는 기존 포함 파일이나 앱의 설치 캐시가 있으면 재사용합니다. 계정 상태를 확인하는 것만으로 다운로드를 시작하지 않습니다.
- 다운로드 파일의 크기와 SHA-256을 검증하고 설치합니다. 설치가 끝나면 이후 연결에서 같은 파일을 다시 내려받지 않습니다.
- 계정 설정과 채팅에 다운로드 진행률, 취소, 실패 후 재시도와 로그인 상태를 함께 표시합니다. 한국어·영어·일본어·중국어 간체·번체 문구를 제공합니다.

## 외부 Grok 웹 연결 안내

- MCP 연결 안내에 Grok 웹의 연결 순서와 화면 예시를 추가했습니다. 외부 Grok 웹 연결과 앱 내부 Grok 계정 연결을 구분해 안내합니다.

## 설치 파일과 서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.5.0.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.5.0-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 플랫폼별 SHA-256 checksum과 빌드 commit·workflow를 기록한 provenance를 함께 제공합니다.
