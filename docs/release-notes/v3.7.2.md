# v3.7.2

글자 영역과 선택한 글자의 배경에 투명도 조절을 추가하고, 자주 사용하는 서식 설정을 위쪽에 모았습니다.

## 배경 투명도와 서식 편집

- **글자 영역 배경:** 블록 전체의 배경 박스를 0~100%로 조절할 수 있습니다. 글자와 외곽선은 유지하면서 배경만 반투명하게 만듭니다. 저장, 다중 선택, 프리셋, 보관 블록과 이미지 출력에도 적용됩니다.
- **글자 배경:** 상세 문자 효과에서 선택한 글자의 배경 투명도를 따로 조절할 수 있습니다. 기존 배경은 100%로 유지되며, 일반 글자와 곡선 글자의 출력에 같은 투명도가 적용됩니다.
- 두 배경 설정 모두 작은 제목 아래에 **색상과 투명도를 2열로 배치**했습니다. 배경을 끄면 입력 위치를 유지한 채 비활성화합니다.
- **프리셋 드롭다운과 글자 영역 배경을 문자 서식 상단으로 이동**해 반복해서 아래로 스크롤할 필요를 줄였습니다.
- 편집 화면의 **블록 배경 투명도**를 조절하거나 일괄 적용하면 숨겨져 있던 배경·테두리 표시를 켜서 결과를 바로 확인할 수 있습니다.

## 검증

- 배경 투명도 기본값, 선택 범위, 마크업·편집 DOM 왕복, 저장·프리셋·분리 패널과 편집기/출력 일치 회귀 테스트를 추가했습니다.
- 실제 편집 컴포넌트로 넓은 창과 좁은 창의 배치, 0%·중간값·100% 적용을 확인했습니다.
- 전체 검사에서 테스트 11,315개가 통과했으며, 커버리지와 빌드 검증을 통과했습니다.
