# v3.7.3

긴 대화와 많은 이미지가 있는 채팅의 안정성을 높이고, 중단된 대화를 이어가는 흐름을 개선했습니다. 기존 대화와 첨부 이미지는 그대로 보존됩니다.

## 대화 이어가기와 안정성

- 중지되거나 연결이 끊긴 대화에 **이어서 진행** 버튼을 추가했습니다. 작성 중인 초안을 유지하면서 기존 대화에서 작업 기록을 확인하며 이어갑니다.
- Codex 대화를 재개할 때 불필요한 전체 과거 본문을 다시 받지 않도록 했습니다. 지나치게 큰 응답이 들어와도 앱 전체가 종료되지 않도록 연결 단위로 처리합니다. ([#158](https://github.com/ucx0204/CarrotMangaTranslator/issues/158))
- 중지 직후 요청이 전송되거나, 이전 연결의 늦은 이벤트가 새 대화 상태를 덮어쓰는 문제를 수정했습니다. 저장이나 연결 중단에 실패해도 앱 작업 취소를 시도합니다.
- 확실히 전송되지 않은 첨부는 이어갈 때 전달합니다. 이미 전송됐을 가능성이 있는 요청과 첨부는 무조건 재전송하지 않고 작업 기록을 확인하도록 했습니다.
- 손상된 기록 하나 때문에 전체 대화 목록과 새 대화 생성이 실패하지 않도록 했습니다. 읽을 수 없는 기록은 표시하고 원본은 보존합니다.
- 늦게 도착한 대화 조회 결과가 최신 응답을 되돌리거나, 실패한 계정 조회가 새 로그인 상태를 지우는 문제를 수정했습니다.

## 긴 대화와 이미지 보기

- 최근 기록부터 표시하고 이전 기록은 나누어 불러옵니다. 긴 도구 작업 묶음도 단계적으로 펼칩니다.
- 과거 대화를 읽는 동안 새 응답이 와도 화면이 맨 아래로 이동하지 않도록 했습니다.
- 화면 가까이 있는 이미지만 작은 미리보기로 읽고, 확대할 때 원본을 불러옵니다. 동시 이미지 읽기를 제한하고 중복 미리보기를 줄였습니다.
- 대화 목록에 재생성 가능한 요약 캐시를 사용해 반복 조회 부담을 줄였습니다. 기존 대화 저장 형식과 원본 이미지는 유지합니다.

## 검증

- 대형 응답, 중지·저장 경합, 첨부 복구, 손상 기록 격리, 늦은 이벤트와 로그인 조회에 대한 재현·회귀 테스트를 추가했습니다.
- 실제 Electron에서 대형 응답 처리와 원본을 보존하는 이미지 미리보기를 확인했습니다.
- Codex·Claude·Grok의 실제 연결에서 이미지 입력, 읽기 전용 도구 호출, 대화 재개와 압축을 확인했습니다.
- 실제 채팅 컴포넌트로 넓은 창과 좁은 창의 긴 기록·이미지·이어가기 배치를 확인했습니다.
