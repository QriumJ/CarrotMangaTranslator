# v3.1.0

v3.0.1 대비 작품별 번역 지침과 페이지 관리 기능을 확장했습니다.

## 작품별 번역 지침과 캐릭터 말투

- `용어/기억 → 번역 규칙`에서 호칭·효과음·기본 톤을 드롭다운으로 고르는 대신 원하는 지침을 직접 작성할 수 있습니다.
- 캐릭터의 말투 분류 선택기를 없애고 `말투` 입력칸으로 통합했습니다. 기존 규칙과 말투 설정도 이어서 사용할 수 있습니다.
- 저장한 번역 지침과 활성 캐릭터의 말투는 누적 번역의 켜짐 여부와 관계없이 번역 요청에 반영됩니다. 작업 재개 시에도 실행 당시 지침을 유지합니다.

## 기존 화에 페이지 추가

- 페이지 목록의 `+`에서 현재 화에 페이지를 추가할 수 있습니다.
- `보관함에 추가` 창은 `새 화 추가`가 기본이며, `페이지 추가`로 전환하면 기존 작품·화와 추가 위치를 선택할 수 있습니다.
- 화의 맨 뒤 또는 지정한 페이지 앞·뒤에 추가할 수 있고, `추가한 페이지만 번역`으로 새 페이지의 번역을 바로 시작할 수 있습니다.

## 페이지 순서·이름 편집

- 페이지 목록의 `+` 옆 `페이지 편집`에서 현재 화 전체를 썸네일 표로 편집할 수 있습니다.
- 여러 페이지를 선택해 드래그하거나 위·아래·맨 앞·맨 뒤·지정 페이지 앞뒤로 옮길 수 있습니다. 자연 정렬과 순서 뒤집기도 지원합니다.
- 이름을 한 장씩 직접 입력하거나 번호 붙이기, 문자 바꾸기·추가·삭제, 이름 목록 붙여넣기, 작품명·화 제목 등을 조합한 형식으로 일괄 변경할 수 있습니다.
- `공백·대소문자·숫자 정리`에서 추가 이름 변경 기능과 정규식 치환을 사용할 수 있으며, 툴팁에서 기능 설명을 확인할 수 있습니다.
- 모든 변경은 먼저 미리보기로 반영되고 실행 취소·다시 실행이 가능합니다. 이름 충돌과 잘못된 이름을 표시하며, 저장할 때 이름과 순서를 함께 확정합니다.
- 이 편집기에서 이름을 변경한 페이지는 이미지·PSD·자동 결과 저장 시 별도의 순서 번호 없이 지정한 이름을 사용합니다. 원본과 이미 저장한 출력 파일은 이동하거나 이름을 바꾸지 않습니다.

## 설치 파일·서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.1.0.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.1.0-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 모델·런타임은 앱에서 별도로 내려받습니다. 플랫폼별 `SHA256SUMS`와 provenance 파일에서 설치 파일 해시와 빌드 커밋을 확인할 수 있습니다.
