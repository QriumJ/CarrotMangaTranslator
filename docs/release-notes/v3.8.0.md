# v3.8.0

앱 안에서 새 버전을 확인하고 다운로드할 수 있습니다. 작품·화의 결과 폴더 관리와 번역 차단 오류 표시도 개선했습니다.

## 앱 내 업데이트

- 실행 시 새 버전을 확인하고 작업 센터에 알립니다. 자동 확인은 설정에서 끌 수 있으며, 다운로드와 설치는 사용자가 직접 시작합니다.
- 작업 센터에서 다운로드 진행률 확인·취소·설치를 이어갈 수 있습니다. Windows는 **재시작하여 업데이트**, macOS는 **설치 파일 열기**를 제공합니다.
- 작업 중에는 설치를 막습니다. 설치 전 편집 내용을 저장하며, 저장 실패나 작업 충돌이 있으면 설치를 중단하고 앱을 유지합니다.
- 다운로드·저장·파일 손상 오류를 구분해서 표시합니다. 보관함·원본·결과물·설정·모델의 저장 위치는 유지합니다.
- **v3.8.0은 설치 파일로 한 번 직접 설치해야 합니다.** 이후 버전부터 앱 내 업데이트를 사용할 수 있습니다. macOS는 DMG를 연 뒤 사용자가 앱을 교체합니다.

## 작품·화와 결과 폴더

- 작품·화 이름 변경창에 **결과 폴더도 함께 변경** 선택을 추가했습니다. 기본으로 켜져 있으며, 끄면 제목만 바꿉니다.
- 보관함의 작품·화 메뉴에서 **제목에 맞춰 폴더 이름 변경**을 실행할 수 있습니다. 사용자 지정 저장 위치는 변경하지 않습니다.
- 같은 이름의 폴더를 덮어쓰거나 합치지 않습니다. 사용자가 수정·추가한 파일을 보존하고, 이동 실패는 해당 화에서 확인하고 재시도할 수 있습니다.
- 현재 화에서 결과물과 이전 폴더를 바로 열 수 있으며, 자동 저장을 꺼도 기존 결과물을 열 수 있습니다.

## 번역 오류 처리

- 제공자가 요청이나 응답을 콘텐츠 정책으로 차단하면 원인을 표시합니다. 빈 응답으로 처리하거나 같은 요청을 불필요하게 자동 재시도하지 않습니다.

## 설치 파일과 서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.8.0.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.8.0-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
