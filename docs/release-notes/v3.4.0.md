# v3.4.0

복제 도장과 치유 브러시를 추가하고, 사이드바 너비와 보관함·페이지 목록의 높이를 조절할 수 있게 했습니다. README의 기능 설명과 실제 앱 화면도 갱신했습니다.

## 복제 도장·치유 브러시

- 브러시 메뉴에서 복제 도장과 치유 브러시를 선택합니다. 현재 보정 결과 또는 페이지 원본을 복사 대상으로 사용하며 번역 글자와 편집 UI는 복사하지 않습니다.
- `Alt/Option+클릭` 또는 원본 지정 버튼으로 복사 위치를 정합니다. 정렬을 켜면 여러 획에서 상대 거리를 유지하고, 끄면 획마다 지정한 위치부터 시작합니다.
- 크기·경도·불투명도를 조절하고 설정을 기억합니다. `[`·`]`로 브러시 크기를 단계적으로 바꾸며, 기존 `Alt+우클릭 드래그` 크기 조절과 `Shift` 직선 그리기를 지원합니다.
- 원본 위치와 복사 내용을 커서로 표시합니다. 치유는 복제 미리보기 후 계산한 결과로 바뀌며, `Esc`로 진행 중인 획이나 계산을 취소합니다. 한 획의 이미지와 마스크는 함께 실행 취소합니다.
- 같은 획에서 방금 그린 픽셀을 다시 복사하지 않도록 원본을 고정합니다. 변경된 타일을 기준으로 계산하고, 치유와 PNG 저장은 작업 스레드에서 처리합니다.
- 계산 메모리 예산을 넘거나 취소·충돌·저장 오류가 발생하면 부분 적용하지 않습니다. 큰 이미지의 디코딩·PNG 저장 비용은 남으므로 획 확정에 시간이 걸릴 수 있습니다.
- 새 도구를 실제 포인터 처리·명령·단축키 경로에 연결하고, 도구 전환과 원본 보기 해제 동작을 기존 보정 도구와 통일했습니다.

## 작업 화면 크기 조절

- 왼쪽 패널 경계를 드래그해 사이드바 너비를 조절합니다. 보관함과 페이지 목록 사이 경계로 두 영역의 높이를 조절합니다.
- 키보드 방향키 조절과 더블클릭 초기화를 지원합니다. 너비를 변경한 경계에는 초기화 버튼을 제공합니다.
- 크기와 패널 접기 상태를 기억하며 좁은 창의 원고 공간을 확보하는 기존 동작을 유지합니다.

## 문서와 검증

- README에 도장·치유, 패널 조절, 색상 팔레트, 채팅, 원문 언어 자동, 작업 이력과 가져오기 옵션 설명을 보강했습니다. 이전 버전에서 추가된 기능은 사용 안내에 반영했으며 이번 릴리스의 신규 기능으로 집계하지 않습니다.
- 실제 프로덕션 컴포넌트를 저장소 QA 도구로 새로 촬영하고 넓은 창·좁은 창의 화면 20개를 확인했습니다. 예제 데이터에 의한 화면이며 모델 품질 측정 자료는 아닙니다.
- 로컬 테스트 10,924개, 커버리지 기준, 정적 검사·빌드·Electron 스모크와 내장 원격 모델 자산 36개 검증을 통과했습니다. Alt 키 해제·창 포커스 상실·도구 전환 시 커서 상태의 회귀 테스트도 포함합니다. 설치 파일은 각 플랫폼 릴리스 workflow에서 패키징·실행 검증합니다.
