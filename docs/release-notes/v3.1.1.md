# v3.1.1

v3.1.0 대비 여러 페이지와 영역을 처리할 때 모델과 렌더러를 반복해서 준비하던 문제를 수정했습니다.

## 모델 반복 로딩 개선

- 기존 블록을 유지하는 번역에서 OCR을 먼저 일괄 처리한 뒤 번역을 진행합니다. 페이지마다 OCR과 Gemma 서버를 다시 시작하던 문제를 수정했습니다. (#136)
- 새 페이지 워크플로의 원문 제거에서 같은 단계의 페이지들이 인페인팅 모델을 재사용합니다.
- MCP 선택 번역은 여러 블록에서 번역 서버를 재사용하고, 선택 OCR은 여러 영역을 한 배치로 처리하며 같은 페이지의 이미지 디코딩을 공유합니다.
- MCP 워크플로 OCR은 같은 화의 미완료 페이지들을 함께 준비합니다.
- GPU 자동 글꼴 분석에서 줄·글자·복구 단계마다 Hayai 모델을 다시 로드하지 않고 한 프로세스를 재사용합니다.

## 중복 처리 감소

- 기존 블록의 OCR에서 이미 지정된 영역을 다시 탐지하는 작업을 생략합니다. 자유 선택 영역의 탐지는 유지합니다.
- 일괄 규칙 적용·검토에서 숨은 렌더러를 재사용하고, 사용하지 않는 PNG 캡처를 생략합니다.
- MCP 일괄 이미지 출력과 워크플로 출력에서도 렌더러를 재사용합니다.
- 작업 취소·실패 시 자원 정리와 페이지별 권한·원본·편집 버전 검사를 유지합니다.

## 설치 파일·서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.1.1.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.1.1-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 모델·런타임은 앱에서 별도로 내려받습니다. 플랫폼별 `SHA256SUMS`와 provenance 파일에서 설치 파일 해시와 빌드 커밋을 확인할 수 있습니다.
