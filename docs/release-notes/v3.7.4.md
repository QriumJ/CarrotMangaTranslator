# v3.7.4

오류 신고에서 핵심 로그가 잘리던 문제를 개선했습니다. GitHub에 한 번 로그인하면 신고 버튼으로 전체 로그 업로드와 이슈 등록을 진행할 수 있습니다.

## 오류 신고

- 현재·이전 실행의 전체 로그를 Gist에 나누어 올리고, 업로드 내용을 검증한 뒤 GitHub 이슈를 등록합니다. 화면 미리보기 길이와 관계없이 선택한 로그를 업로드합니다.
- 긴 오류 메시지·스택·원인 정보와 작업 프로세스 로그가 저장 단계에서 잘리지 않도록 개선했습니다. API 키·경로·작품 텍스트 정제는 유지합니다.
- 연결이 끊기면 기존 업로드와 이슈를 확인해 이어갑니다. GitHub 로그인 정보는 운영체제 암호화 저장소를 사용합니다.
- 인증 코드를 크게 표시하고 복사 버튼을 추가했습니다. 로그인·인증·신고 상태에 맞는 버튼을 표시하며 불필요한 안내 문구를 줄였습니다.

신고 내용과 연결된 로그는 공개됩니다. 자동 정제를 적용한 뒤 업로드합니다.

## 설치 파일과 서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.7.4.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.7.4-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 플랫폼별 SHA-256 checksum과 빌드 commit·workflow를 기록한 provenance를 함께 제공합니다.
